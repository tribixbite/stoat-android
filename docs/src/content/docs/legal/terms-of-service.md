## Description of Services

### Stoat for Android

Stoat for Android is an open-source native Android client for the Stoat/Revolt chat platform. It provides access to your Stoat account, servers, channels, and messaging features.

### Stoatcord Bot

The Stoatcord Bot is a Discord application that provides:

- **Channel migration**: Import Discord server channel structures into a Stoat server.
- **Message bridging**: Relay messages in real time between linked Discord and Stoat channels.
- **Slash commands**: Server management commands for linking, unlinking, and managing bridges.
